This is a major new release of the P5 Guidelines, which introduces some significant new material as well as implementing an unusually large set of other changes and error corrections. Since the last release in March 2011, members of the TEI community have proposed over 60 feature requests and reported about the same number of errors; dealing with these has kept the TEI Council busy, and most of these tickets have now been closed. See further the release notes at[ http://www.tei-c.org/release/doc/tei-p5-doc/readme-2.0.html](/release/doc/tei-p5-doc/readme-2.0.html "Release Notes")
