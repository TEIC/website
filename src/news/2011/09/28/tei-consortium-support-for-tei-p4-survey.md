Dear TEI-L


When the TEI Consortium released TEI P5 in November 2007 it<br/>
promised 5 years of ongoing support for TEI P4. Support for TEI<br/>
P4 will continue until November 2012.  As this is just over a<br/>
year away the TEI Technical Council thought it should gradually<br/>
phase out support for TEI P4 over this period.


As a first step in this direction it has been suggested that we<br/>
de-emphasize TEI P4 on the website (e.g. by stopping search<br/>
engines indexing it). Before proceeding with this we want to<br/>
gauge how many ongoing/active projects there might be out there<br/>
still using TEI P4 and so have set up the following survey:


<http://www.surveymonkey.com/s/2N95CY5>


This collects some information we will use to assess how much TEI<br/>
P4 is still being used and what steps we should take in phasing<br/>
out its support. It also collects some additional information<br/>
potentially of use to the TEI Technical Council. TEI P4 has,<br/>
since the publication of TEI P5, been considered deprecated and<br/>
since then we have encouraged use of TEI P5 by new projects. Even<br/>
if you have never used TEI P4, only TEI P5, we would appreciate<br/>
you filling in the survey so we can capture that (negative<br/>
results are indeed results in this case).


Many thanks,


-James
