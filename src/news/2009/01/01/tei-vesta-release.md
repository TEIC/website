The Vesta desktop TEI processor is now available.  Vesta is a simple Java desktop application which lets you run conversions on TEI files.<br/>
                It understands what to do with ODD files, and can generate schemas and documentation.  It can process simple<br/>
                TEI XML files and make HTML, LaTeX, FO and Word 2007 .docx output.


A MacOS version can be downloaded from<br/>[<br/>https://sourceforge.net/project/showfiles.php?group_id=106328&package_id=298013<br/>](https://sourceforge.net/project/showfiles.php?group_id=106328&package_id=298013 "")<br/>
                and Debian/Ubuntu users can pick up a “tei-vesta” package by adding the right APT source to their local setup (see [<br/>http://tei.oucs.ox.ac.uk/teideb/](http://packages.tei-c.org/deb/ "")).<br/>
                The source is available on [<br/>http://sourceforge.net/projects/tei/<br/>](https://sourceforge.net/projects/tei/ "")Sourceforge.
