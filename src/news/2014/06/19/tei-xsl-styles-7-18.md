Dear colleagues,


I have made a new release of the TEI Stylesheets in the usual places;<br/>
if you use Debian packages or the TEI framework updater in oXygen,<br/>
you’ll see them come over.


amongst other things, this release


* implements the Pure ODD markup more thoroughly<br/>
* fixes many small problems in Excel and Word to TEI (you’ve no idea how devious a docx file can be…), thanks to Magdalena Turska<br/>
* improves Markdown <-> TEI<br/>
* improves WordPress -> TEI (similar unimaginable horrors)


there remains an unresolved error in some ODD processing<br/>
(<https://github.com/TEIC/Stylesheets/issues/21>)


<https://github.com/TEIC/Stylesheets> is the place to report<br/>
errors, and to send in fixes (as some people are doing,<br/>
which is great).<br/>
