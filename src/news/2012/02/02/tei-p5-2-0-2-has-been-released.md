The 2.0.2 release of TEI P5 is a minor release fixing a number of small issues, mostly typographical errors and formatting problems, discovered in the 2.0.1 release. 2.0.1 itself consisted of only minor tweaks to the 2.0.0 release. See further the release notes [http://www.tei-c.org/release/doc/tei-p5-doc/readme-2.0.2.html](/release/doc/tei-p5-doc/readme-2.0.1.html).
