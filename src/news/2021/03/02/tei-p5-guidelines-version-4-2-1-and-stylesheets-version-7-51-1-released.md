The TEI Consortium has released version 4.2.1 of the TEI P5 Guidelines and version 7.51.1 of Styelsheets, a follow-up version of the TEI P5 Guidelines version 4.2.0 and Stylesheets version 7.51.0, where we surfaced an issue with the conversion of the constraints on attributes to XHTML. This problem did not effect the schemas, but made the “Schema Declaration” portion of the references pages of several elements unreadable. For more details, please see the [release notes](/release/doc/tei-p5-doc/readme-4.2.1.html).
