The TEI Consortium has released version 4.2.2 of the TEI P5 Guidelines and version 7.51.2 of Styelsheets, a follow-up version of the TEI P5 Guidelines version 4.2.1 and Stylesheets version 7.51.1, where an issue was noticed concerning the controlled value lists of certain type attributes. For more details, please see the [release notes](/release/doc/tei-p5-doc/readme-4.2.2.html).
